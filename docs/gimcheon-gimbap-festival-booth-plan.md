# 2026 김천 김밥축제 체험부스 기획안

**축제장 전체가 게임판이 되는 김밥 술래잡기**

팀 동심지키미가 자체 개발한 GPS 술래잡기 앱 "경찰과 도둑"으로, 김밥축제 방문객이 직접 뛰며 즐기는 체험부스를 운영합니다.

---

## 한눈 요약

| 항목 | 내용 |
| --- | --- |
| 콘셉트 | 김밥을 다 먹고 뚱뚱해진 도둥이가 흘린 밥풀 자국을 방문객(냥파)이 쫓는다 |
| 핵심 | 축제장 전체를 무대로 실제로 뛰는 GPS 게임. 플리마켓 부스 중 유일한 방식 |
| 주제 적합성 | 게임의 핵심 규칙(위치 공개=밥풀)이 김밥 스토리와 그대로 맞물림 |
| 집객 | 뚱보 도둥이 추격과 대형 실시간 현황판으로 지나가는 사람도 모임 |
| 접근성 | QR 한 번, 설명 30초. 설치 없이도 웹으로 즉시 참여 |
| 확산 | 결과 인증샷이 SNS로 퍼져 김천과 축제 홍보로 이어짐 |

---

## 1. 왜 김밥축제에 맞는가

의적 도둥이가 곳간의 김밥을 훔쳐 백성에게 나눠주려다, 너무 맛있어 다 먹어버립니다. 배가 빵빵해져 뒤뚱뒤뚱 도망치며 밥풀을 흘리고, 냥파 순찰대가 그 자국을 따라 쫓습니다.

이 스토리가 곧 게임 규칙입니다. 억지로 붙인 테마가 아니라, 규칙과 주제가 처음부터 하나입니다.

| 스토리 | 게임 규칙 |
| --- | --- |
| 흘린 밥풀 자국 | 도둑 위치가 주기적으로 공개됨 |
| 김밥 먹느라 늦은 냥파 | 경찰 출발 대기 시간 |
| 갇히는 곳간 | 감옥 구역 |
| 축제장 무대 | 실제 축제장 경계를 그린 게임 구역 |

---

## 2. 핵심 - 우리 앱으로 하는 GPS 술래잡기

축제장 일대를 무대로, 방문객이 진짜로 뛰며 도둥이를 쫓는 체험입니다. 화면 안에서 끝나는 게임이 아니라 축제 공간 자체를 게임판으로 쓰는 유일한 부스입니다.

**진행 방식**

- 도둥이는 스태프가 배 부푼 분장으로 맡습니다. 멀리서도 보이고, 안전하며, 그 자체가 볼거리입니다.
- 방문객은 냥파로 참여해 지도의 밥풀 자국을 보고 쫓고, 정해진 반경 안에서 체포 버튼을 누르면 승리합니다.
- 냥파 4명에서 8명, 30분 간격 정시 진행으로 하루 여러 차례 돌립니다.

**축제용 설정 (짧고 쉽게)**

| 설정 | 축제값 | 이유 |
| --- | --- | --- |
| 라운드 시간 | 5분에서 8분 | 방문객 회전율 |
| 위치 공개 주기 | 20초에서 40초 | 뚱뚱한 도둥이가 밥풀을 자주 흘림. 초보도 쉽게 추적 |
| 경찰 대기 | 30초에서 1분 | 도주 시간만 짧게 |
| 게임 구역 | 부스 인근으로 좁게 | 안전, 미아 방지, 관람 |

---

## 3. 부스 구성 - 3코너로 대기 없이

메인 추격이 도는 사이에도 방문객이 계속 체험하도록, 강도와 소요 시간이 다른 세 코너를 함께 둡니다.

| 코너 | 내용 | 소요 | 역할 |
| --- | --- | --- | --- |
| 밥풀 추격전 (GPS 앱) | 정시마다 진행하는 실제 추격 | 5분에서 8분 | 하이라이트, 구경거리 |
| 김밥 도둑 잡기 (웹 미니게임) | 화면을 탭하는 게임, 설치 불필요 | 30초에서 60초 | 상시 체험, 어린이 |
| 포토부스 | 캐릭터 프레임 인증샷 | 1분 | SNS 확산, 대기 손님 |

부스 대형 화면에는 실시간 현황판(오늘 참여 수, 미니게임 순위, 게임 구역 지도)을 띄워 부스의 활기를 눈에 보이게 합니다.

---

## 4. 누구나 30초면 참여 (전 연령 접근성)

- **QR 즉시 참여**: 스캔하면 세팅 없이 다음 라운드에 바로 합류합니다.
- **설치 없는 웹**: 미니게임과 포토부스는 설치 없이 됩니다. 앱 설치를 원하면 QR이 스토어로 안내합니다.
- **예비 폰 2대에서 3대**: 폰이 없거나 설치를 꺼리는 방문객에게 대여합니다.
- 뛰는 추격은 청년, 웹 미니게임은 어린이, 관람과 포토는 가족. 온 가족이 각자 즐길 거리가 있습니다.

---

## 5. 안전과 운영

체험부스에서 가장 중요하게 보는 부분입니다. 처음부터 안전하게 설계했습니다.

| 항목 | 대비 |
| --- | --- |
| 추격 안전 | 도둥이는 스태프 고정, 구역을 좁게, 위험 구역은 경계에서 제외 |
| 미아와 사고 | 구역 경계에 스태프 배치, 어린이는 보호자 동반 |
| 설치 거부 | 무설치 웹 참여와 예비 폰 |
| 네트워크와 배터리 | 핫스팟, 보조배터리 |
| 우천 | 웹 미니게임과 포토 위주 실내형 운영으로 전환 |
| 개인정보 | 최소 정보만 수집, 촬영물은 현장 동의 후 활용 |

---

## 6. 축제가 우리 부스를 선정하면 얻는 것

주최 측 입장에서 이 부스가 축제에 주는 이점입니다.

| 이점 | 설명 |
| --- | --- |
| 주제 몰입 강화 | 김밥을 소재로 직접 구현한 콘텐츠라, 축제 정체성을 부스가 함께 키웁니다 |
| 체류 시간 증가 | 추격, 미니게임, 포토로 방문객이 축제장에 더 오래 머뭅니다 |
| 축제장 전역 활기 | 부스 한 칸이 아니라 축제장 공간을 무대로 써서, 사람 동선이 축제 전역으로 퍼집니다 |
| 무료 홍보 효과 | 인증샷과 라이브 화면이 SNS로 퍼져 마케팅 비용 없이 축제가 홍보됩니다 |
| 차별화된 볼거리 | 기술 기반 GPS 체험은 플리마켓에서 희소해, 축제의 격과 미디어 소재를 더합니다 |
| 낮은 운영 리스크 | 검증된 앱, 스태프 고정, 무설치 대안으로 사고 위험이 낮습니다 |
| 지역 청년 서사 | 지역 청년팀이 자체 개발한 앱으로, 지역 혁신과 청년 활동 홍보 포인트가 됩니다 |
| 성과 리포트 | 참여 수치가 기록으로 남아, 축제 결산 자료로 제공할 수 있습니다 |

---

## 7. 실현 가능성

- **대부분 준비됨**: 게임 앱, 웹 미니게임, 포토부스가 이미 있습니다.
- **신규 개발 최소**: QR 즉시 참여, 밥풀 자국 표시, 실시간 현황판, 포토 결과 프레임 정도만 축제용으로 더합니다.
- **재활용**: 미니게임은 김밥 테마로 리스킨, 포토부스는 프레임 교체로 대응합니다.
