# 행사 링크와 QR (#171)

행사 부스, 포스터, 블로그에 붙일 링크를 어드민에서 한 번 등록하면 짧은 주소 `copsandrobbers.app/q/<코드>` 와 인쇄용 QR 이 나와요.
그 링크로 몇 명이 와서 스토어로 넘어갔는지는 지표 화면 유입 경로 탭 맨 아래 "링크와 QR" 에서 봐요.

## 왜 만들었나

예전에는 행사 QR 과 링크트리에 `/download?utm_source=...&utm_medium=...&utm_campaign=...` 긴 주소를 손으로 이어 붙였어요(#144).

- 주소가 길면 QR 에 담을 글자가 많아져 점이 촘촘해져요. 같은 크기로 뽑으면 칸 하나가 작아져 포스터나 부스 거치대에서 멀리서 잘 안 읽혀요
- 사람이 꼬리표를 지어 붙이다 보니 같은 행사가 다른 이름으로 갈리거나, App Store 캠페인 토큰(출처-캠페인-구분, 30자)을 넘겨 조용히 잘렸어요
- 링크를 만들어도 결과는 유입 경로 탭의 캠페인 표에서 이름을 찾아 읽어야 했어요

## 흐름

```
QR / 짧은 주소  copsandrobbers.app/q/nowon
  -> /q/[code] (app/q/[code]/route.ts)  등록된 꼬리표를 붙여 302
  -> /download?utm_source=booth&utm_medium=qr&utm_campaign=nowon-festival-2026
  -> 기기를 보고 스토어로. Play 는 referrer, App Store 는 캠페인 토큰 ct 로 꼬리표를 이어 넘김 (lib/download/campaign.ts)
```

- 302(임시 이동)로 보내요. 꼬리표를 나중에 고칠 수 있어야 해서예요. 308 이면 브라우저가 옛 목적지를 기억해요(`/apply` 와 같은 이유)
- 없는 코드, 잘못된 코드, 저장소 오류는 꼬리표 없이 `/download` 로 보내요. 포스터를 찍은 사람을 오류 화면에 세우지 않아요
- `/q/` 는 robots 에서 빼요. 검색에 걸릴 페이지가 아니에요

## 등록 규칙 (lib/download/links.ts)

| 칸 | 규칙 | 왜 |
| --- | --- | --- |
| 주소 코드 | 소문자, 숫자, 하이픈 2자에서 24자. 처음과 끝은 글자 | 주소에 그대로 들어가고, 짧을수록 QR 이 성기다 |
| 출처, 캠페인, 구분 | 영문, 숫자, `- _ .` | `/download` 가 이 밖의 글자는 조용히 버린다(campaign.ts SAFE) |
| 매체 | 비우면 `qr` | 유입 채널에서 "직접 입력과 QR" 로 묶인다(channels.ts) |
| 출처-캠페인-구분 | 이어서 30자 안 | App Store 캠페인 링크 화면이 30자까지만 받는다. 넘으면 잘려 다른 링크와 같은 토큰이 될 수 있다 |
| 출처, 매체, 캠페인 조합 | 링크마다 하나 | 결과를 이 조합으로 찾는다. 구분은 GA4 다운로드 집계에 칸이 없어 링크를 가르지 못한다 |

## 결과 (새로 모으지 않는다)

GA4 수집(`lib/metrics/ga4/run.ts`)이 이미 출처|매체|캠페인 조합별로 쌓는 값을 링크의 꼬리표로 찾아 기간 합으로 보여 줘요(`linkResult`).

| 칸 | 어디서 |
| --- | --- |
| 방문 | 사이트 세션 `session_campaign` (지표 화면의 webCampaigns) |
| 스토어로 이동 | 다운로드 버튼과 `/download` 이벤트 `download_source` (downloadCampaigns, 이번에 더함) |
| Android 첫 실행 | 앱 신규 사용자 `first_user_campaign`. Play referrer 로 갈린 것만 |

iOS 다운로드는 넣지 않아요. App Store 상세 리포트가 5명 미만 칸을 빼서 거의 비고, 앱은 어느 링크로 왔는지 몰라요.
행사 코드를 가입 화면에서 받는 일은 앱 저장소의 일이라 아직 안 했어요.

## QR

- 화면에서 1024px PNG 로 내려받아요(둘레 여백 4칸, 오류 정정 M). 둘레 여백(quiet zone)은 QR 규격(ISO/IEC 18004)이 4칸을 요구해요. 없으면 포스터 무늬와 섞여 안 읽혀요
- 인쇄 전에 실제 크기로 뽑아 폰 두세 대로 찍어 봐요

## 손으로 할 것

- `supabase/migrations/0012_metrics_links.sql` 을 Supabase SQL Editor 에서 실행해요. 실행 전에는 화면에 "0012 마이그레이션을 실행해 주세요" 가 떠요
- 이미 뽑아 둔 `/download?utm_...` QR 은 그대로 써도 돼요. 같은 꼬리표로 링크를 등록하면 그 결과도 이 표에 잡혀요
