# 카피(문구) 말투 가이드

사용자에게 보이는 모든 문구에 적용한다. 지향점: 채널톡·데브시스터즈처럼
**다정하지만 군더더기 없는** 한국어. 실제 사이트 문구에서 뽑은 규칙이다.

## 기본 말투

- **해요체**로 끝낸다: "-해요", "-돼요", "-이에요". 합쇼체("-합니다")는 약관류에만
- **짧은 완결문**. 한 문장에 하나의 말만. 개조식·명사 나열로 끝내지 않는다
  - 좋음: "스마트폰 하나면 준비 끝이에요."
  - 나쁨: "스마트폰 하나로 간편한 준비 가능"
- 느낌표는 진짜 환호할 때만 한 번. 남발 금지
- 물결(~), 이모티콘(^^), 반말은 쓰지 않는다. 이모지는 문서·가이드에선 허용, 사이트 UI에선 절제
- 예외: 세계관 콘텐츠(사건 파일·속보 등)는 신문·수사 파일 문체("-이다", "-되다")를 쓸 수 있다

## 내용의 규칙

- **기능이 아니라 사용자의 행동·이득**을 말한다
  - 좋음: "진행은 앱이 알아서 해요." / "이제 뛰면 돼요"
  - 나쁨: "자동 진행 기능을 제공합니다"
- 숫자는 구체적으로: "최대 50명까지 함께 플레이" (모호한 "다수", "많은" 금지)
- 부풀리지 않는다. "최고의", "혁신적인" 같은 광고어 대신 사실을 담백하게

## 캐릭터 (세계관 원본은 팀 노션 "세계관 최종 정리" 문서)

무대는 **치즈타운**. 500년 봉인된 **황금 치즈**와 그 안의 **전설의 치즈 레시피 양피지**가
봉인 해제식 전날 밤 사라진 도난 사건(CASE FILE TC-0408)이 세계관의 축이다.
마지막 레시피 계승자 **그랜드 체다 경**은 이미 별세했고, 사건은 미궁이다.

### 냥파 (담당 형사)

- 파란 고양이. 치즈타운 경찰서 **특수치즈수사대** 소속, 라이트 모드(파랑 테마)의 얼굴
- **검거율 1.8%**. 치즈를 매우 좋아하고(최애는 에멘탈) 수사보다 시식이 앞선다는
  내부 지적이 있으나, 후각만큼은 서 내 최고
- 완벽한 히어로가 아니라 **어딘가 허술해서 정이 가는** 캐릭터로 쓴다.
  유능·시크·카리스마 형사로 묘사하지 않는다
- 대표 대사 톤: "혹시… 남은 치즈는 없나요?" / "이번엔 진짜, 진짜로 잡는다"
- 에셋: `public/photobooth/cop*.svg`, `public/characters/police*.svg`

### 도둥이 (유력 용의자)

- 회색 쥐, **반(反)치즈주의자**, 전과 없음. 다크 모드(초록 테마)의 얼굴
- "쥐는 치즈를 좋아한다"는 고정관념이 죽도록 싫다. 치즈가 사라지면 그 오해도
  사라질 거라 믿는다 - 동기는 확실한데 결정적 증거가 없다
- **범인으로 단정하지 않는다.** "유력 용의자", "용의자 도주 중"까지만.
  진범이 따로 있을 가능성은 세계관의 확장 여지이므로 카피가 닫아버리면 안 된다
- 밉지 않은 말썽꾼 톤. 악역화 금지
- 에셋: `public/photobooth/thief*.svg`, `public/characters/robber*.svg`

### 사용 규칙

- **둘은 대등하다.** 함께 등장시키는 게 기본(쫓고 도망치는 구도), 한쪽만 반복 노출하지 않는다
- 이름은 "냥파", "도둥이". "경찰 캐릭터/도둑 캐릭터" 같은 건조한 표현은 카피에서 지양
- 캐릭터 추가 가능성이 열려 있다(예: 황금 치즈 안에 잠들어 있던 치즈 조각 캐릭터 구상).
  기존 카피가 "둘뿐"임을 전제하지 않게 쓴다

## 세계관 어휘

- 경도 = 경찰과 도둑의 애칭
- 발자국 = 흔적·기록의 은유 ("팀이 남기는 발자국들"). 게임에서 도둑 위치가 주기마다
  발자국으로 공개되는 데서 온 모티프
- 치즈타운 · 황금 치즈 · 전설의 레시피 · 특별수사본부 · 검거·도주·수사 = 세계관 콘텐츠의 무드
- 남용 금지: 상시 페이지(홈·게임 소개 등)에선 한 화면에 한두 번, 세계관 페이지에선 자유롭게
- **대등 원칙**: 한쪽 시점으로 고정되는 표현("수사일지" 등)은 상시 노출 영역에 쓰지 않는다

## 구두점·표기

- 나열은 가운뎃점: "개발기, 행사 후기, 그리고 뒷이야기" 또는 "iOS · Android"
- 긴 대시(—) 금지, 하이픈(-) 사용
- 날짜는 "7월 4일 (토)", 시간은 "낮 12시-오후 5시" 형식
- 앱·게임명은 "경찰과 도둑", 팀명은 "동심지키미"로 통일 (영문 표기 지양)

## 톤 예시 모음 (실제 사용 중)

- 히어로: "경찰과 도둑이 돌아왔어요"
- 빈 상태: "아직 첫 이야기를 준비하고 있어요 / 곧 팀의 발자국으로 채워질 자리예요."
- 안내: "화면을 누르면 바로 찍혀요"
- 감사: "함께 남긴 네컷, 오래 간직할게요. 다음 행사에서 또 만나요!"
- CTA: "앱 다운로드하고 수사 시작" (동사로 끝나는 행동 유도)
