# 이야기 쓰는 법 ✍️

우리 홈페이지의 **이야기**(copsnro66ers.site/blog)는 노션에 쓴 글이 그대로 올라가요.
개발 지식 없이, 노션에 글 쓰듯 쓰면 됩니다. 아래만 지켜주세요!

## 1. 새 글 만들기

"이야기" 데이터베이스에서 **+ 새로 만들기**를 누르고, 표의 칸들을 채워요.

| 칸 | 뭘 쓰면 되나요 | 예시 |
| --- | --- | --- |
| 제목 | 글 제목 | `서울 게임 타운에 다녀왔어요` |
| 슬러그 | 글의 인터넷 주소. **영어 소문자와 하이픈(-)만** | `seoul-game-town` |
| 요약 | 목록에서 제목 아래에 보이는 한두 문장 | `처음 나간 오프라인 행사에서 생긴 일` |
| 작성자 | 본인 이름. 팀원 이름이면 프로필 사진이 자동으로 붙어요 | `윤지희` |
| 날짜 | 글 올리는 날 | |
| 태그 | 글 종류. 골라서 선택 | `행사`, `개발`, `팀` |
| 공개 | ✅ **체크해야 홈페이지에 올라가요.** 쓰는 중엔 꺼두세요 | |

## 2. 커버 이미지 넣기 (꼭!)

글 페이지를 열고 맨 위 **"커버 추가"**를 눌러 이미지를 넣어주세요.
이 이미지가 **목록의 썸네일 + 글 상단의 대표 이미지**가 돼요. 가로로 긴 사진이 예뻐요.

## 3. 본문 쓰기

평소 노션 쓰듯 쓰면 돼요. 이런 것들이 홈페이지에 예쁘게 나와요:

- 일반 글, **굵게**, *기울임*, 링크
- 제목 1 · 2 · 3 (소제목으로 써주세요)
- 글머리 기호 / 번호 목록 / 할 일 체크박스
- 인용, 콜아웃(이모지 박스), 토글(접히는 상자)
- 이미지 (캡션도 나와요)
- 코드 블록, 표, 구분선, 북마크

### 안 나오는 것들 ⚠️

**동영상, 유튜브 임베드, 컬럼(단 나누기), 수식, 파일 첨부**는 홈페이지에서 보이지 않아요.
유튜브를 걸고 싶으면 링크나 북마크로 넣어주세요.

**커스텀 이모지**(우리 팀이 등록한 캐릭터 이모지)도 안 나와요 —
노션이 외부로 데이터를 안 내보내주는 항목이라 어쩔 수 없어요.
글자 사이엔 **기본 이모지**(🚓 🐭 같은 것)를 써주세요 → 잘 나와요.

### 알아두면 좋은 것

- **글자 색을 바꿔도 홈페이지엔 반영 안 돼요.** 홈페이지가 라이트/다크 모드 색을 알아서 입혀줘요. 강조하고 싶으면 굵게나 콜아웃을 쓰세요.
- 이미지를 **드래그로 줄여도 반영 안 돼요.** 대신 아래 "이미지 크기" 방법을 쓰세요.

## 4. 이미지 크기 조절하기

이미지 캡션(사진 아래 설명) **맨 앞에 태그**를 붙이면 크기가 바뀌어요:

| 캡션에 이렇게 쓰면 | 이렇게 나와요 |
| --- | --- |
| `우승자 시상 장면` | 크게 (기본) — 본문보다 살짝 넓게 |
| `[중간] 부스 전경` | 본문의 3/4 크기, 가운데 |
| `[작게] QR 코드` | 본문의 절반 크기, 가운데 |

태그(`[작게]` 부분)는 홈페이지에서 자동으로 지워지고 뒷부분만 캡션으로 보여요.
설명 없이 크기만 조절하고 싶으면 `[작게]`만 써도 돼요.

## 5. 구글 검색에 잘 걸리게 쓰는 팁 🔍

우리 글은 구글·네이버 검색에 자동으로 등록돼요. 조금만 신경 쓰면 더 잘 노출돼요:

- **제목에 사람들이 검색할 만한 단어**를 넣어주세요.
  (`행사 다녀옴` ❌ → `서울 게임 타운 포토부스 운영 후기` ⭕)
- **소제목은 순서대로**: 큰 단락은 "제목 1", 그 안의 작은 단락은 "제목 2"로 써주세요.
  "제목 1" 없이 "제목 3"부터 쓰는 식으로 건너뛰지만 않으면 돼요.
- **요약은 검색 결과에 그대로 보이는 문장**이에요. "클릭하고 싶어지는 한두 문장"으로 써주세요.
- **슬러그도 내용과 관련된 영어 단어**로. (`post-1` ❌ → `seoul-game-town-recap` ⭕)

## 6. 올리기 & 고치기

- 다 썼으면 **공개에 체크** → 늦어도 1~2분 안에 홈페이지에 올라가요.
- 올라간 글도 노션에서 고치면 5분 안에 반영돼요.
- 글을 내리고 싶으면 공개 체크를 끄면 돼요.
