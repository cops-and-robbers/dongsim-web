# 다국어(i18n)

한국어(기본) + 영어 + 일본어. **라이브러리 없이** 이 Next 16이 지원하는 사전(dictionary) + `proxy.ts` 방식으로 구성한다.

## 핵심 원칙

- **한국어는 루트**(`/`, `/game`), **영어는 `/en`, 일본어는 `/ja`** 접두어. 기존 한국어 URL·SEO를 그대로 보존한다.
- **문구(카피)는 `lib/i18n/messages.ts`가 단일 출처.** 컴포넌트에 하드코딩하지 않는다. (기존 `constants.ts`에 있던 게임·팀 카피도 전부 이리로 이동)
- **직역 금지.** 각 언어권에서 실제 쓰는 마케팅 말투로 쓴다 (`docs/copy-guide.md`). 일본어는 현지 명칭 **ケイドロ**(警察/泥棒) 사용.
- 번역 안 된 페이지(블로그·약관·행사 도구)는 `/en`·`/ja`에서 **노출하지 않는다** - 내비에서 숨기고, 그 경로로 오면 `proxy.ts`가 한국어로 리다이렉트.

## 파일 지도

| 파일 | 역할 |
| --- | --- |
| `lib/i18n/config.ts` | 로케일 목록·기본값, 경로 헬퍼(`localizedPath`·`stripLocale`), `BRAND_NAME`·`logoSrc`·`appIconSrc`, `alternateLanguages`(hreflang), `TRANSLATED_PATHS` |
| `lib/i18n/messages.ts` | **페이지 본문 카피 단일 출처** (ko/en/ja). `getMessages(locale)`. 서버 컴포넌트에서 사용 |
| `lib/i18n/chrome.ts` | 헤더·푸터 등 **공통 UI 문구**. 클라이언트에서 쓰므로 messages와 분리해 번들을 작게 유지 |
| `components/i18n/LocaleProvider.tsx` | 경로로 로케일 판별 → `useLocale()` 제공, `<html lang>` 갱신 |
| `components/i18n/SkipLink.tsx` | 접근성 - 본문 바로가기 (로케일별 문구) |
| `components/layout/LanguageSwitcher.tsx` | 언어 전환 (푸터에 배치) |
| `proxy.ts` | 미번역 `/en`·`/ja` 경로를 한국어로 리다이렉트 (이 Next는 middleware가 proxy로 바뀜) |

## 라우팅 구조

- 한국어: 기존 `app/*` 그대로.
- 영어·일본어: `app/en/*`, `app/ja/*`의 **얇은 라우트**가 공용 `*Sections` 래퍼(`HomeSections`·`GameSections`·`TeamSections`)를 `locale`만 바꿔 렌더.
- 헤더/푸터는 루트 레이아웃에서 렌더되고, `useLocale()`로 언어를 감지해 로고(로케일×다크)·내비·문구를 바꾼다.

## 번역된 범위

| 페이지 | ko | en·ja |
| --- | --- | --- |
| 홈 `/` | ✅ | ✅ (미니게임 티저는 ko 전용) |
| 게임 `/game` | ✅ | ✅ (폰 목업 화면 텍스트 포함) |
| 팀 `/team` | ✅ | ✅ 히어로·연혁·수상·QA (구성원 미리보기는 ko 전용) |
| 다운로드 `/download` | ✅ | 브라우저 언어로 문구만 (noindex 리다이렉트라 라우트 없음) |
| 블로그·약관·행사 도구 | ✅ | ko 전용 (미번역) |

## 작업 방법

### 이미 번역된 페이지의 문구 수정
`lib/i18n/messages.ts`에서 `ko`/`en`/`ja` 세 곳을 함께 고친다. 끝.

### 새 페이지를 다국어로 만들기
1. `messages.ts`의 ko/en/ja에 그 페이지 섹션 추가.
2. 섹션 컴포넌트가 `copy` prop을 받게 리팩터(하드코딩 제거).
3. 공용 `XSections({ locale })` 래퍼를 만들어 `getMessages(locale)`로 렌더.
4. `app/en/x/page.tsx`·`app/ja/x/page.tsx` 얇은 라우트 추가(메타는 `title: { absolute }`로 템플릿 우회, hreflang은 `alternateLanguages`).
5. `config.ts`의 `TRANSLATED_PATHS`에 `"/x"` 추가(안 하면 proxy가 한국어로 리다이렉트).
6. `app/sitemap.ts`에 `/en/x`·`/ja/x` + `alternates` 추가.

## 규칙 요약

- 섹션 컴포넌트의 문구 prop 이름은 **`copy`** (한 글자 변수 금지).
- hreflang·sitemap의 언어 맵은 **`alternateLanguages(url, path)` 헬퍼**로 (복붙 금지).
- 로고·앱아이콘은 `logoSrc(locale, dark)`·`appIconSrc(locale)`, 브랜드명은 `BRAND_NAME[locale]`.
- 회사명(동심지키미)의 영어·일본어 표기는 **Team Dongsim / チーム・トンシム** (정식 로마자명 Dongsimjikimi는 저작권 표기용).
